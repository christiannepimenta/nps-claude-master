# NPS Claude Master

Pesquisa de satisfação do treinamento Claude Master integrada com Google Sheets.

## Como usar

1. Crie uma planilha no Google Sheets com os cabeçalhos: `score`, `feedback`, `strength`, `prior_knowledge`, `timestamp`
2. Copie o ID da planilha (da URL)
3. Acesse este formulário
4. Cole o ID da planilha
5. Compartilhe o link com os participantes

Todas as respostas vão automaticamente para sua planilha do Google Drive.
